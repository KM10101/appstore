# 使用说明

## 账户与密码

首次访问Langfuse Web界面时，您需要注册一个管理员账户。请访问您设置的端口（默认为3000），然后点击"Sign up"创建您的账户。


## 功能

- [x] 全链路追踪：记录所有LLM调用、中间步骤和用户会话
- [x] 性能指标监控：实时跟踪成本、延迟、质量等关键指标
- [x] 调试与日志检查：通过UI查看复杂日志，识别低评分对话或性能瓶颈
- [x] 提示词管理：支持提示词的版本管理、参数配置
- [x] 仪表板监控：在仪表板中查看质量、成本和延迟指标
- [x] 会话跟踪：跟踪多步骤对话或智能体工作流程
- [x] 用户监控：监控每个用户的成本和使用情况
- [x] 大语言模型评估：收集并计算LLM完成的分数

## 文档

<https://langfuse.com/docs>


## 组件说明

本部署方案包含以下组件：

- **Langfuse Web**：主Web界面和API服务
- **Langfuse Worker**：异步处理事件的Worker
- **PostgreSQL**：主数据库，用于事务性工作负载
- **Clickhouse**：高性能OLAP数据库，存储跟踪、观察和分数
- **Redis**：快速内存数据结构存储，用于队列和缓存操作
- **Minio**：对象存储，用于持久化事件和大文件

## 安全建议

1. 部署后请立即修改默认的密码和密钥
2. 建议通过反向代理配置HTTPS访问
3. 不建议将除Web界面外的其他服务端口暴露到公网
