## 使用方式

默认 `1Panel` 安装在 `/opt/` 路径下，如实际安装路径不同，请根据需要调整以下命令。

### 下载源码

使用 Git 命令获取应用商店配置：

可在 `1Panel` 的计划任务中选择类型为 `Shell 脚本`，添加并执行以下命令，或直接在终端中运行：

```shell
git clone -b localApps https://github.com/KM10101/appstore.git /tmp/appstore-localApps
```

### 更新应用商店

将下载的应用配置复制到 1Panel 本地应用目录：

```shell
cp -rf /tmp/appstore-localApps/apps/* /opt/1panel/resource/apps/local/
```

清理临时文件：

```shell
rm -rf /tmp/appstore-localApps
```

完成后，在 1Panel 应用商店中刷新本地应用即可生效。
